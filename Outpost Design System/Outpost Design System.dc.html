Outpost Design System
v1.0

A command center for outreach.

Outpost is a dense internal tool people live in for hours. This system trades decoration for clarity: quiet neutrals, one confident accent, semantic color only where it carries meaning, and type tuned for tables. Toggle the theme in the header — every component below responds live.

Restraint
Color is a signal, not a texture.
Density
More rows visible, less scrolling.
Trust
Evidence and scores read at a glance.
Low strain
Soft contrast, dark mode as a peer.
